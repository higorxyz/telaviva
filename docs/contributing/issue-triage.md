# Issue Triage Guide

## Labels
- `bug`
- `enhancement`
- `needs-triage`
- `dependencies`
- `ci`
- `severity:blocker`
- `severity:major`
- `severity:minor`

## Triage flow
1. Confirm reproducibility
2. Classify severity and component
3. Define acceptance criteria
4. Link related issues/PRs
5. Prioritize in backlog

## Bug severity baseline
- blocker: breaks core flow or production usability
- major: feature broken with workaround or high impact
- minor: low-impact bug, cosmetic issue, edge behavior
